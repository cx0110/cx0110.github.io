# YouTube Digest

> **作者**:zarazhangrui
> **链接**:https://github.com/zarazhangrui/youtube-digest
> **类型**:浏览器扩展(Chrome / Firefox) · 内容生产工具

## 一句话定位

打开 YouTube 视频 → 摘要逐字稿 → 自动翻译成中文 → 解释术语 + 提取章节和金句 + 自动生成笔记。

## 使用场景

- 🚀 **YouTube 学习加速器**:看英文技术分享 / TED / 教程时,直接拿到中文要点 + 金句
- 🎬 **Vlog 字幕提取**:把喜欢的 vlog 主播的中字版下载下来本地收藏
- 📚 **二手资料沉淀**:把 YouTube 视频的金句变成可搜索的 Obsidian 笔记
- 💡 **Vibe Coding 上手项目**:作者明确把 YouTube Digest 列为「很好的 vibe coding 上手项目」(2026-10-04 推送原话)

## 我的使用感受

我主要用 YouTube Digest 看英文技术分享,**翻译质量足够日常参考** — 学术讲词会翻错一些,但工程实战类内容很准确。逐字稿能让我跨过「听不清主播嘴瓢」的问题,直接抓到原文核心句子。

## 亮点 & 局限

| 亮点 | 局限 |
|---|---|
| 浏览器内一键操作,无需后端 | 需要稳定的国际网络 |
| 摘要 + 翻译 + 章节 + 金句 一气呵成 | 长视频(>1h)处理速度慢 |
| 开源,可二次定制 | 需要 OpenAI/Claude API(免费额度内可) |
