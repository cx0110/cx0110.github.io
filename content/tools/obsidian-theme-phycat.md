# Obsidian Theme — Phycat

> **作者**:sumruler
> **链接**:https://github.com/sumruler/obsidian-theme-phycat
> **类型**:Obsidian CSS 主题

## 一句话定位

Obsidian 用 colorful 多彩主题 — 适合喜欢颜色区分 + 高密度可视化的笔记党。

## 使用场景

- 🎨 **多彩笔记党**:不喜欢单色 default 主题,Phycat 给每个 block 提供鲜明颜色
- 📚 **多项目并行**:ob-vault 我用 Phycat 区分 02_Research 子目录的颜色块
- 🌙 **日夜两态切换**:dark / light 都做了精心调色

## 我的使用感受

这是我 obsidian-vault 的主力主题。**配色密度高**但不刺眼,**目录树颜色提示让找笔记变快** — 在 ob-vault 这种 1700+ 文件的大仓库里尤其有用。Phycat 对中文支持良好,不像有些英文主题对 CJK 字体处理有问题。

## 亮点 & 局限

| 亮点 | 局限 |
|---|---|
| 配色密度高 + 不刺眼 | 某些 UI 元素定制激进,需要适应 |
| 对大仓库友好(目录色块) | 性能开销略大于默认主题 |
| 中文字体 fallback 完善 | 不喜欢彩色的人会觉得太花 |
